# 文档导航

## 当前有效

- `product/当前运行事实.md`：当前运行路径、数据源、端口、阶段和禁止事项的唯一状态锚点。
- `product/功能清单-v4.md`：当前产品能力清单。
- `product/需求池.md`：尚未进入实施范围的需求。
- `architecture/`：当前仍有效的技术边界、契约和架构决策。
- `design/`：当前仍有效的页面与交互设计冻结记录。
- `development/`：当前开发、运行、Git 和部署约定。
- `tasks/`：仍在执行或需要继续跟踪的任务。
- `daily-contributions/`：按日期追加的实际修改记录。

## 历史归档

- `archive/architecture/`：已结束或已被替代的架构路线与评审过程。
- `archive/product/`：历史产品授权、验收和封板过程。
- `archive/design/`：历史设计方案与验收记录。
- `archive/architecture/sqlite-migration/`：已停用的 SQLite 迁移路线。

归档文档用于追溯，不作为当前实现依据。当前运行事实发生变化时，先更新 `product/当前运行事实.md`。
