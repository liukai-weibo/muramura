# 想试试事项渐进补充说明 — 稳定契约审阅记录

> 审阅日期：2026-07-21
> 依据：专项测试 3 项通过、全量测试 17 文件 / 66 项通过、typecheck / build:h5 / diff 检查通过的 QA 验收报告。
> 结论：**稳定契约审阅通过，允许转交前端实施。**

## 【技术结论：可行】

实际实现与轻量技术评审一致：内容补充被实现为 `Item.content` 的专用、显式、受状态保护的更新能力，没有扩张为通用事项编辑。

前端现在可以实现“想试试事项详情中按需编辑 → 显式保存 / 取消 → 草稿保护”的体验，但只能通过 `ItemApplicationService.updateItemContent()` 调用，不得访问 IndexedDB 或绕过状态保护。

## 【已核对的稳定契约】

### Contracts

```ts
interface UpdateItemContentInput {
  content: string
}

interface ItemRepository {
  updateContent(id: string, input: UpdateItemContentInput): Promise<Item>
}
```

该契约仅承载内容更新；不存在 `updateItem()` 或可编辑标题、状态、日期、标签等其他字段的泛化入口。

### Application

```ts
ItemApplicationService.updateItemContent(id: string, content: string): Promise<Item>
```

Application 层将页面输入传入 Repository；页面不能直接写入表，也不应在状态迁移、关闭详情或切换事项时自动调用。

### Repository 写入不变量

```text
读取 Item
→ 不存在或 deletedAt 存在：抛出“事项不存在”
→ status !== idea_to_try：抛出“仅可为想试试事项补充说明”
→ content.trim()
→ 仅更新 content 与 updatedAt
→ 返回更新后的 Item
```

已确认：

- 空字符串合法，代表显式清空；
- 不创建或改写 `ItemStatusEvent`；
- 不改标题、状态、`createdAt`、复盘、方法应用或其他关系；
- 不涉及 Schema、Dexie Migration、JSON 备份格式、备份版本或事项状态机；
- 搜索直接读取 `Item.content`，保存后的新内容自然成为查询事实。

## 【前端行为边界】

### 可显示编辑入口的条件

只有详情中当前可信 `selectedItem` 同时满足：

```text
status === idea_to_try
+ 不在回收站
```

前端此判断只用于显示与交互。最终保存是否允许，以 Repository 写入时再次读取到的真实状态为准。

### 保存

```text
用户点击“保存”
→ 调用 itemApplication.updateItemContent(selectedId, draft)
→ 成功时以返回 Item 更新详情和列表
→ 按既有 updatedAt 规则重排列表
→ selectedId 保持不变
→ 仅成功后清除草稿并退出编辑态
```

如全局搜索结果层当前打开，保存成功后应重新执行当前搜索，或关闭结果层，避免旧 `content` 摘要继续展示。

### 取消

```text
用户点击“取消”
→ 仅丢弃该事项本地草稿
→ 不调用 updateItemContent()
→ 不改写 Item.content
```

### 保存失败、状态变化与草稿保护

- 保存失败时必须保留对应事项 ID 的本地草稿；
- `事项不存在` 或 `仅可为想试试事项补充说明` 都是正常、可解释的失败，不允许自动重试、自动保存或回写；
- 用户编辑中开始执行时，页面不得阻断状态迁移，也不得自动保存说明；后续保存应由 Repository 安全拒绝并保留草稿；
- 切换事项、列表刷新、搜索刷新或旧保存请求返回，均不得让事项 A 的结果覆盖事项 B 的详情或草稿；
- 页面可按事项 ID 保存短生命周期草稿，但不得把草稿写入 IndexedDB、备份或全局持久化状态。

## 【前端最低验收】

1. 只有活跃 `idea_to_try` 事项出现补充说明编辑入口；
2. 保存前不写库；取消不写库；
3. 保存成功后详情、列表排序和已打开搜索结果一致；
4. 可显式清空已保存内容；
5. 不存在、回收站、状态已变化、存储失败时均保留草稿并给出可解释提示；
6. 编辑不阻断开始执行，开始执行不自动保存；
7. 切换事项与异步返回不串写详情或草稿；
8. H5 人工验证后，数据层 66 项既有回归继续通过。
