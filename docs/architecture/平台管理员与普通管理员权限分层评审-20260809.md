# 平台管理员与普通管理员权限分层评审

## 结论

有条件可行，允许实现三级角色：`member`、`ordinary_admin`、`platform_admin`。

## 规则

- 平台管理员最多一个，初始平台管理员通过 Migration 016 标记并由应用层永久保护。
- 普通管理员只能查看和管理普通成员，不能查看或操作平台管理员、普通管理员或自己。
- 平台管理员可以管理普通成员和普通管理员，但不能通过用户管理接口操作平台管理员。
- 角色变更只允许 `['member']` 与 `['member', 'ordinary_admin']`；平台管理员不由普通用户管理接口授予或撤销。
- AI 参数配置继续只允许平台管理员。

## 技术边界

- 修改 Contracts、Application、API 管理员中间件、MySQL Repository、Migration 016 和 H5 用户管理展示。
- Repository 在事务内重新锁定操作者和目标，不能依赖前端隐藏按钮。
- Backup、AI Prompt、Provider、SSE、Rive、微信小程序、Docker 与部署脚本不在本轮范围。

## 验收重点

验证初始管理员不可降级、删除、恢复、改名、管理接口重置密码或撤销会话；普通管理员只能完成成员管理；第二个平台管理员和越权 ID 请求均被拒绝。
