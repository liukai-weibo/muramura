# MaruMaru 桌面端原生化布局与 Windows 交付评审

日期：2026-08-10
分支：fast-ui

## 结论

有条件通过。桌面端继续使用 React/Taro 编译后的 WebView 内容，Tauri 负责窗口、托盘和快捷键；不引入 SQLite，不改变 API、数据库、Prompt、SSE、备份或业务语义。

## 已确定实现

- 使用无框、透明 Tauri 窗口和自定义标题栏。
- 标题栏提供拖拽区域、窗口控制、前进/后退、搜索和快速捕获入口。
- 关闭窗口隐藏到托盘，托盘支持恢复和退出。
- 注册 Alt + Space 唤醒窗口；Ctrl + N、Ctrl + F、Esc 由桌面桥接层转为应用内动作，H5 环境不注册原生事件。
- 行动、长期探索、方法使用一级导航下的工作台三栏布局；中栏宽度限制为 280px～420px，默认 340px。
- AI 页面继续保留现有双栏与流式逻辑。
- 生产 NSIS 使用 `apps/client/dist`，不依赖开发端口 `10086`；开发模式可继续使用热更新。

## 边界与风险

- 透明窗口必须由根容器提供稳定背景，最大化时重点检查四边白边、圆角和任务栏边界。
- 文本选择仅在 Markdown、代码、帮助文档、表单和搜索区域恢复；根容器、导航和标题栏禁止选择。
- 未全局屏蔽右键菜单，避免破坏编辑器和代码块操作。
- 多屏与高 DPI、托盘 Alt + Tab 表现需要 Windows 11 实机验收，自动构建不能替代该验证。

## 明确不做

本轮不处理 H5 独立视觉改造、微信小程序适配、离线业务数据、自动更新、HTTPS、SQLite、Rust 原生 UI 或 Framer Motion。

## 网络与托管解耦

- 10086 仅属于 Web 端静态托管和 `/api` 代理。
- Tauri 开发和生产均从 `apps/client/dist` 加载本地静态资源，不使用 10086 或新增 10087。
- Web 环境 API Client 始终请求相对路径 `/api`；Tauri 环境默认直连 `http://127.0.0.1:32146`，并允许 `TARO_APP_API_BASE_URL` 覆盖。
- API 已放行 `tauri://localhost` 与 `http://tauri.localhost`，桌面端不经过 Web 代理访问 API。
