## 修复项
- 修复：个人档案「保存失败，请稍后重试」（保存报 400 `VALIDATION_FAILED`）。根因：`apps/api/src/hono/routes/daily-diet.ts` 动态路由 `GET/PUT /{entryDate}` 注册在静态 `GET/PUT /profile` 之前，Hono 先匹配先注册，`/profile` 被 `/{entryDate}` 捕获、日期正则校验失败返回 400。修复：`/profile` 移至动态日期路由之前注册。
- 修复：弹窗保存只提交本次改动的字段，未改字段会被服务端覆盖清空（如只改体重后身高/性别/健康状态丢失）。修复：保存前先读服务端当前档案，与本次改动合并后整行 PUT。
- 修复：体重栏位 `SMALLINT UNSIGNED` 截断小数，81.5 被存成 81。修复：Migration 033 将 `weight_kg` 改为 `DECIMAL(5,1) UNSIGNED NULL`，Repository SELECT 以 `CAST(weight_kg AS DOUBLE)` 保持数值契约。
- API 已以新源码重启（单条 `node --import tsx src/main.ts`，进程树 1924→5908，监听 127.0.0.1:32146）；经 10086 代理全链路 E2E 通过：注册→登录→PUT 完整档案（含 aiPrompt）→合并保存体重 81.5→GET 读回字段全部保留（身高 178/性别/目标/活动量/健康状态/AI 提示词）→清空 aiPrompt 读回 undefined；未认证访问 `/daily-diet/{date}` 与 `/profile` 均 401（路由正常解析，不再 400）。
