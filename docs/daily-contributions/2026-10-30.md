# 2026-10-30 每日贡献

## 增加项

1. 时间轴视图改为「整天一屏」：几何比例不再写死 56px/小时，改为按 `ResizeObserver` 量到的容器高度换算（`timelineScale(railHeight)`，`minuteHeight = 高度 / 1440`），容器 `overflow: hidden`、不再有内部滚动条；刻度步长自动取值保证标签间距 ≥34px，`00:00`–`24:00` 全在框内，窗口缩放即时跟随。
2. 时间轴卡片收成一行：高 22px、`white-space: nowrap` + `text-overflow: ellipsis`，删掉原两行 `-webkit-line-clamp`；左右位置改由 JS 按分栏算像素，去掉 `left/right` 定宽规则。
3. 新增同刻卡片横向分栏：`placeTimelineCards` 支持 `lane`/`laneCount`，最多 3 栏，栏数按重叠连通块计算并压实到 `0..n-1`（单独一组的卡片占满整行），栏不足才向下顺延；贴底卡片顶边钳制在 `railHeight - 卡片高`。
4. 手记页隐藏右侧 AI 复盘面板：不再渲染 `DailyNoteAiPanel`，页面网格由三栏 `18% / 52% / 30%` 改为 `232px / 1fr`（含 1100px 断点），`DailyNotesPageProps` 去掉 `onItemsChanged`/`onItemCreated`，`index.tsx` 同步去掉传参；面板组件与样式保留以便接回。
5. 默认视图改为时间轴：存储键升为 `marumaru.daily-note-view.v2`，未设置时默认 `timeline`，之后用户显式切换照常记住。
6. 时间轴交互改为单击选中、双击进文本视图：新增 `onSelect`，`onDoubleClick` 与键盘 Enter 触发 `onOpenInText`；拖拽改时间吸附到 5 分钟。
7. 文本视图新增跳转落点提示：从时间轴双击进来时该行 `scrollIntoView` 并高亮 1.4 秒（`prefers-reduced-motion` 下改为静态描边）。
8. 「未定时间」旧数据条带化：由竖排列表改为横排 + 省略号 + `max-height: 52px`，不再挤占时间轴高度。
9. 新增 `timelineScale`、`timelineLabelHours`、`isMajorHour`、`snapMinute` 纯函数；`tests/timeline-layout.test.ts` 重写为 20 项，覆盖一屏不变式、刻度步长、分钟像素互算、贴底钳制、分栏与同栏不重叠。

## 修复项

1. 修正「时间轴点了空白处没反应」的静默失败：补录依赖 `noteRef.current`，手记还没读完时点击会直接返回且没有任何提示；改为时间轴在手记未就绪时不接受点击，空态提示显示「正在读取这一天的手记…」。
2. 修正一页展示下拖拽过于灵敏：1 像素约 2 分钟，手指轻微移动就会改掉几十分钟；改为吸附到 5 分钟。
3. 修正竖排「未定时间」块把时间轴挤出一屏：条带化后固定 36px 左右，时间轴仍完整可见。
