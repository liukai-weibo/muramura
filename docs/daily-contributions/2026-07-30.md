- 将本机隔离 UAT 数据库初始化为包含账户、会话及业务 owner 列的 Schema 5 空库。
- 将当前登录用户作用域接入事项、方法、复盘、探索主线、回收站、搜索和 Dashboard 的 MySQL 读写链路。
- 增加双用户全业务隔离、跨用户资源统一不可见和十个业务集合归属校验场景。
- 增加显式目标账户的初始个人数据归属命令及十集合事务摘要。
- 增加按当前会话用户导出、预览和恢复 Backup V1/V2/V3 的隔离能力。
- 增加 H5 注册、登录、退出、当前会话恢复和未认证登录门。
- 增加当前账户展示、会话过期返回登录门及 Cookie 会话业务请求接入。
- 增加退出按钮的启用态鼠标悬停反馈。
- 增加随机临时数据库、随机回环 API 与隔离浏览器的账户登录门端到端 QA 场景。

## 修复项

- 将本机日常一键启动器和本机启动说明的健康门由 Schema 4 修正为 Schema 5。
- 修复本机停止脚本只终止监听子进程、父启动链可能继续保留或重建服务的问题。
- 修复既有 API 集成夹具未建立认证会话导致的回归失效。
- 修复无用户作用域的 Repository 旧直测对 owner 列的非必要依赖。
- 修复旧 MySQL 测试随机标题超过既有二十字限制的问题。
- 修复 Backup 恢复会清理或覆盖其他用户业务数据的问题。
- 修复旧认证请求可能覆盖新认证上下文的问题。
- 修复登录、注册或退出结果未知时可能丢失草稿或误判认证结果的问题。
- 修复 main 与 ty 合并时账户 owner scope、结构化业务错误和探索主线批量查询之间的兼容冲突。
