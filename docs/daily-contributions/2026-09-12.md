# 2026-09-12 每日贡献记录

## 增加项
1. 手机端「事项」页移除页内标题「事项」（与底部 Tab 同名冗余）：删除 `MobileItems` 顶部 `.mobile-section-heading` 标题块，「＋ 新建事项」按钮上移为面板首元素（`margin-top` 由 1rem 改为 0），后续内容随之整体上移。Playwright 实测面板内不再出现「事项」标题文本、新建按钮位于面板顶部。
2. 手机端「手记 / 事项」Tab 切换改常驻双面板（keep-alive）：两个面板同时挂载、各自状态保留，切换仅做 `display:none` 显隐（隐藏面板不可交互），不再每次切换重新卸载 / 挂载并重新拉取全量数据，消除切换时的零点几秒延迟。Playwright 实测切换耗时由约 500ms+ 降到 22–38ms，且手记编辑器草稿在切换后原样保留（`MobileIndex` 增加 `notesMounted / itemsMounted` 首次访问挂载标记，CSS 增加 `[data-panel]` 显隐规则）。

## 修复项
1. 手机端「调整长期探索」弹窗内可选探索与「移除归入」文字透明问题加固：对 `.mobile-explore-option` / `.mobile-explore-remove` 及其后代文字节点追加 `!important` 的 `color` 与 `-webkit-text-fill-color`，并对全局 `.mobile-page taro-button-core` 追加 `color:inherit!important` / `-webkit-text-fill-color:currentColor!important` 与文字节点 `opacity:1!important`，对抗 Taro vendor 的 `taro-button-core{color:#000}` 默认色与禁用半透明态，消除样式注入顺序/旧缓存导致的透明字残留（对齐 2026-09-10 修复项 2 的根因加固）。
2. 手机端顶栏「退出」按钮与用户名重叠、事项卡「复盘 / 调整探索」不等宽问题：定位到 Taro vendor 内置 `taro-button-core{width:100%;margin-left:auto;margin-right:auto;display:block}` 默认规则，按钮通用规则补 `width:auto;margin:0` 兜底，由各场景（新建事项 / 筛选 / Tab / 主按钮）显式重设整行宽，消除 auto margin 顶偏与整行撑宽导致的布局重叠与不等宽。
