## 修复项
- 审计中心模块/操作筛选按钮（audit-center-chip 及筛选按钮全部状态）文字显示为白色像透明：根因是 Taro 按钮默认 `-webkit-text-fill-color: #fff` 覆盖 `color`，WebKit 渲染取 text-fill 值导致白字；修复为在未激活/激活 chip 及筛选按钮各状态同时显式双写 `color` 与 `-webkit-text-fill-color`（含 text/taro-text-core 子元素），playwright 加载 dev server 计算样式实测 chip 文字色 #413c35 / 激活白字 #fffdf9、text-fill 同值。
- 审计中心【按用户名】【关键词】【时间筛选】输入框输入任意字符即白屏（整页 React 卸载）：根因是 `onInput` 在函数式 setState 的 reducer 内读取 `event.currentTarget.value`，该回调延迟到下一次渲染才执行，此时 React 已把合成事件 currentTarget 置为 null，读 `.value` 抛 TypeError；修复为在事件回调内先同步提取 `const value = event.currentTarget.value` 再传入函数式更新，4 个输入框（用户名/开始日期/结束日期/关键词）全部改写，playwright 实测输入后页面存活、筛选与清除均正常。
