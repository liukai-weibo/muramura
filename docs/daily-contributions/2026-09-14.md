# 2026-09-14 每日贡献记录

## 增加项
1. 手机端「事项」页改为「长期探索 → 事项」两级导航：顶部筛选「进行中 / 已复盘」移除，事项 Tab 默认显示活跃长期探索列表；每个探索显示名称 + 进行中事项数 + 最近事项摘要，点击进入该探索详情，仅展示进行中事项，并可对事项执行复盘 / 调整探索；列表页保留「未归入长期探索」「已删除 / 不可用的探索」兜底分组，避免旧数据丢失。新增 `mobile-track-card`、`mobile-track-detail-heading`、`mobile-back-button` 等样式与 `MobileItemsView` 内部视图状态。
2. 手机端新建事项支持归入长期探索：探索详情页新建自动归入当前探索（`explorationTrack: { type: 'existing', trackId }`），探索列表页新建可点选「归入长期探索」后创建；无可用长期探索时保持可创建未归入事项。
3. 手机端长期探索列表页把「未归入长期探索」由整组事项卡片收成单条堆叠入口，点击进入折叠详情后再逐条展示，减少首页信息密度；探索详情顶部返回按钮由大按钮改为紧凑小图标。
4. 手机端事项详情返回按钮移入顶栏左上角：详情视图下顶栏左侧由用户名替换为返回按钮，点击返回探索列表；事项视图状态提升到 `MobileIndex`，由父组件统一控制顶栏与内容区。
5. 手机端「调整长期探索」弹窗限制最大高度并在可选项区域内部纵向滚动，避免可选长期探索过多时弹窗被无限拉高。
6. 桌面端开放正文文字选取与复制：解除 Taro vendor 在 `.taro-app-wrap` 上的 `user-select:none`，正文、事项标题/补充说明、长期探索描述等均可拖选并复制；侧边导航、标题栏、标签页、按钮保持不可选，并补充 `::selection` 高亮色。
7. 桌面端「点击进入编辑」与「拖选复制」互不干扰：事项补充说明与长期探索描述卡片不再在按下时直接 `preventDefault`，改为按下后按抬起位移判断，单击仍进入编辑，拖选只复制文字不进入编辑。
