## 增加项
1. 手机端「事项」页改为「长期探索 → 事项」两级导航：顶部筛选「进行中 / 已复盘」移除，事项 Tab 默认显示活跃长期探索列表；每个探索显示名称 + 进行中事项数 + 最近事项摘要，点击进入该探索详情，仅展示进行中事项，并可对事项执行复盘 / 调整探索；列表页保留「未归入长期探索」「已删除 / 不可用的探索」兜底分组，避免旧数据丢失。新增 `mobile-track-card`、`mobile-track-detail-heading`、`mobile-back-button` 等样式与 `MobileItemsView` 内部视图状态。

4. 手机端事项详情返回按钮移入顶栏左上角：详情视图下顶栏左侧由用户名替换为返回按钮，点击返回探索列表；事项视图状态提升到 `MobileIndex`，由父组件统一控制顶栏与内容区。
