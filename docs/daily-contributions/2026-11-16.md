# 2026-11-16 发布记录

## v0.3.2（Patch）

窗口外轮廓与内部界面的视觉修整，外加两处线上/桌面缺陷修复，不新增独立模块，按 Patch 从 0.3.1 升至 0.3.2。

- 桌面窗口圆角改由 Windows 11 DWM 合成器裁形（`DWMWA_WINDOW_CORNER_PREFERENCE`），不再用 `SetWindowRgn` 硬裁 24px：四角为抗锯齿弧线，无阶梯状硬切口。最大化时切换 `DWMWCP_DONOTROUND` 并清空区域裁剪；无边框窗口的 1px 浅色描边用 `DWMWA_BORDER_COLOR = DWMWA_COLOR_NONE` 去掉。Windows 10 无该属性时回落到区域裁剪，半径降到 10px 减轻锯齿。
- 窗口底色统一为 `#faf8f5`：`tauri.conf.json` 的 `backgroundColor`、`app.scss` 的 `html/body/#app/page`、`.app-shell`、`.auth-gate-shell` 与奶油画布的兜底值全部对齐，消除边缘色差露白；深色标题栏底下那条浅色分隔线改为深色系。
- 修复裸域名 `https://muramura.icu` 登录被拒：API 允许来源补上该 origin，其余来源判定不放宽。
- nginx 对裸域名返回 308 跳转到 `https://www.muramura.icu`，保留路径与查询参数；跳转在反代之前生效。
- 桌面端 HTML5 拖拽可用：`tauri.conf.json` 关闭 `dragDropEnabled`，任务可从今日拖入长期任务池；任务行「放弃」改名「移入长期」，行为不变。
- 新增 4 个测试文件：`desktop-window-frame`（5）、`api-origin`（9）、`canonical-domain`（2）、`desktop-drag-drop`（2）。
- 实测截图（100% 缩放、可见窗口边界）：左上/左下角弧线拟合半径 8px、误差 0.10，角部 12–15 个过渡像素，说明经过合成器抗锯齿；最大化时四角为直角且无亮线。视觉模型此次不可用，验收改为像素测量。
- 定向测试 56 项通过；`cargo check` 通过；H5 构建通过；typecheck 仍只有既有 `indexeddb-item-status-history` 三处错误。
- Schema 38、备份 V14 不变；生产安装包仍连接 https://www.muramura.icu 。
- 本地已构建签名安装包 `Muramura_0.3.2_x64-setup.exe`：6,678,898 字节，签名 420 字节，SHA-256 `b5b96e36d37db184edeaf20a253f701afe91524c2991d0ca68c693fb622e109a`。
- 已发布：`83b979f`（功能与视觉）、`755b7a8`（更新清单签名修正），tag `v0.3.2`；Release https://github.com/liukai-weibo/muramura/releases/tag/v0.3.2 非 draft / 非 prerelease，安装包与 `.sig` 已上传，GitHub asset digest 与本地 SHA-256 一致。
