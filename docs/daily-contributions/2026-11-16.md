# 2026-11-16 发布记录

## v0.3.0（Minor）

本批新增独立任务模块，按版本规则从 0.2.0 升为 0.3.0。包含：

- 任务、长期任务池与已完成列表；完成后保留三分钟删除线，可再次点击勾选恢复。
- 圆角长方形添加入口原地展开为输入框，确认、回车或点外部添加；失败保留内容。
- 淡莫兰迪任务底色、任务删除、今日与长期任务双向拖动。
- 长期任务池手动展开保持、拖动临时展开后收起；抽屉与箭头同步柔和动画。
- 长期探索按账户隔离的本机置顶偏好（先排序再分页，刷新保留）。
- 首页今日推进卡暂时隐藏，手记填满顶部。
- 修复时间轴删除按钮被卡片 pointer capture 吞掉的问题。
- Migration 038 新增任务表，最低 Schema 38；备份 V14 包含任务并兼容旧版恢复。V14 保留睡眠校验，拒绝缺失或重复任务 ID。
