# 每日贡献 2026-11-11

## 增加项

1. 首页情绪卡改为「情绪波动」：主体显示「主问句 + 副文案」，去掉「今天发生了什么？」小标题；文案库为本地写死的 102 组配对（原始清单实际是 102 条，不是 100 条），不依赖网络与存储。
2. 12 小时轮换：按东八区本地 00:00 / 12:00 切换（不是 UTC 的 8 点 / 20 点），同一周期内稳定，卡片在边界自动刷新；循环按文案总数取模。
3. 用户可见文案统一：工作台页签「事件」→「情绪」、按钮「＋ 记录情绪」、弹窗「记录情绪波动 / 编辑情绪记录」、字段「此刻的想法或感受」、详情「情绪记录」、保存提示「已记录情绪波动」、空态与读取文案、日历 aria 全部改为情绪语义。
4. 内部标识保持不动：`mood_entries`、`MoodEntry`、`/mood-entries`、备份 V6–V10、审计模块与 `moodLevel` 均未改名，无 Schema/API 变更。
5. 首页情绪卡去掉「情绪波动」小标题，只保留主问句 + 副文案，文案区垂直居中、内边距加到 24px，问句 18px。
6. 方法模块暂时停用：新增 `METHODS_ENABLED = false`，隐藏工作台「方法」页签、方法页面、复盘弹窗「方法处理」区块、提交按钮的方法后缀、全局搜索里的方法结果与占位文案、回收站的方法筛选与方法条目；数据、API、备份与代码保留，改回 `true` 即恢复。
7. 侧栏顺序改为 首页 → 手记 → 灵感todo → 圈圈 AI 助手（只换渲染顺序，路由与徽标不变）。
8. 新增 `docs/product/版本规则.md` 并在 `AGENTS.md`、`README.md` 落地：Patch=修补/UI/重构，Minor=新增完整模块，Major=破坏性变更；本轮含情绪轮换新功能，下一版按 Minor 记 `0.2.0`。

## 决策

- 「无小标题」理解为只保留「情绪波动」分类标签，下面直接是主问句 + 副文案；本轮进一步按用户要求连分类标签也去掉，只留问句与副文案。
- 12 小时边界用东八区本地时间，避免用户感知为早上 8 点、晚上 8 点换词。
- 文案数量与原始清单一致（102 条），没有为了凑整删除内容。
- 方法模块是「暂时隐藏」而非删除：统一用 `METHODS_ENABLED` 控制，避免以后恢复时到处找入口。
- 版本号按改动级别而不是发布次数递增；新增完整模块不得只升 Patch。

## 任务模块（已实现，未发布）

- Migration `038_tasks.sql` 新建 `tasks`（active / pool / completed，completed_at 仅完成态有值），`MYSQL_REQUIRED_SCHEMA_VERSION` 37 → **38**；本机已执行 038，`/health` schemaVersion=38。
- 契约 `tasks.ts`（Task、状态机、标题 120 字）、`TASK_INVALID` / `TASK_NOT_FOUND`、审计模块 `task`、备份 **V14**（V13 恢复自动补空任务）。
- Application `TaskApplicationService`：创建 active/pool、领取 pool→active、完成 active→completed（界面隐藏）、放弃 active→pool、仅任务池可删除。
- MySQL 仓储 `MySqlTaskRepository` 按 owner 隔离；API `/tasks`（GET/POST）与 `/{id}/claim|complete|abandon`、DELETE。
- 前端侧栏新增「任务」，页面两栏「今日任务 / 任务池」：行内添加、勾选完成、悬停「放弃」、池内「领取」；无日期。
- 完成后保留 **3 分钟**删除线状态，期间可「撤销」；右下角新增「已完成 N」入口，弹层列出已完成任务与完成时间；已完成列表**不显示**撤销按钮（后端已支持 `restore`，仅三分钟窗口暴露）。
- 任务支持删除（今日与任务池可删，已完成不可删）；支持在「今日任务」与「任务池」之间拖动切换状态（HTML5 拖拽）。
- 任务池改为右侧抽屉：默认隐藏，只留右侧箭头；点击箭头展开，展开后持续保留，点击抽屉外自动收起；拖拽今日任务到箭头会展开抽屉以便投放。
- 版本：新增独立模块按规则为 **Minor**，正式发布时升至 **0.3.0**。
