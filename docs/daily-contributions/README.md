# 每日贡献记录

> 本目录用于按日期沉淀当天对 Knowledge_Base 的真实项目贡献。
>
> 命名规则：`YYYY-MM-DD.md`，例如 `2026-07-21.md`。

## 记录规则

- 每次完成一轮 `typecheck`、`test`、`build:h5`、`git diff --check` 或 H5 人工验收后，同步当天文件。
- 同一天持续追加到同一个文件，不重复创建多个日期文件。
- 只记录已发生的修改、验证事实、关键决策与未关闭风险；不记录未实施愿望或推测。
- 本记录不替代 PRD、架构评审、QA 报告、产品验收记录、需求池或 Git 提交；它是面向日常复盘的工作事实索引。
- 若当天没有实质项目修改或验证，不强制创建空文件。

## 单日模板

```markdown
# YYYY-MM-DD 每日贡献

## 今日完成

- [模块 / Sprint] 完成了什么，以及用户或系统行为的变化。

## 验证

- `命令或人工 UAT`：结果。

## 关键决策

- 已冻结的产品、设计或架构结论。

## 未关闭项 / 下一步

- 风险、待验证项或下一责任岗；没有则写“无”。

## 关联记录

- PRD、架构评审、QA 报告、验收记录或 Git commit。
```
