# 2026-09-03

## 增加项
- 新功能：所有记录情绪的接口（H5 情绪页、首页弹窗等统一经 `POST /api/v1/mood-entries`）在成功记录情绪后，自动同步追加到今日手记：`MoodEntryApplicationService.create` 新增可选 `dailyNotes` 依赖（复用 `DailyNoteApplicationService`），写入 `【情绪】{等级标题}` + 情绪内容 + 可选 `感受对策：{response}`，时间（`HH:mm`）由今日手记追加逻辑自动加上；`apps/api/src/hono/services.ts` 装配共享 `dailyNoteService` 实例。情绪记录失败不影响手记（静默降级 `console.warn`），未装配依赖时跳过同步；编辑/删除情绪不触发。

## 修复项
- 修复：记录情绪成功后，首页手记卡片与手记页面未即时追加内容。修复：`mood-page.tsx` 在创建情绪成功后派发 `daily-note-content-changed` 事件（仅新增时，编辑不派发），首页手记卡与手记页通过既有订阅刷新今日手记。
- 修复：情绪同步手记格式去掉 `【情绪】` 前缀（用户验收反馈），手记中直接写等级标题（如 `轻松愉悦`）+ 内容 + 可选 `感受对策：…`；回退文案改为 `心情 {等级}`。
- 修复：首页「今日情绪」弹窗保存成功后未派发 `daily-note-content-changed`（情绪记录→首页手记卡/手记页不即时刷新）。修复：`index.tsx` 首页情绪弹窗 `onSave` 在 `createMoodEntry` 成功后补派发事件（与工作台情绪页一致）。
- 页面调整：手记情绪同步格式进一步精简（用户验收反馈）：去掉等级标题行（不再写 `平静如常` 等），并更名为「感受：」；最终手记块为 `HH:mm + 情绪内容 + 可选 感受：…`。
- 修复：手机端兼容页面（`pages/mobile/index`）快速记录/自动保存后，桌面端 html 页面（首页手记卡与手记页）不同步更新。根因：`daily-note-content-changed` 仅在同一窗口内 `window.dispatchEvent`，同源不同标签页 / Tauri WebView / 局域网手机端（不同源）收不到。修复：新增 `apps/client/src/pages/index/daily-note-sync.ts` 统一通知与订阅（本地 CustomEvent + BroadcastChannel + localStorage/storage 事件 + focus/visibilitychange + 可见时 10s 跨源轮询兜底），手机端与桌面端所有写手记入口改调 `notifyDailyNoteChanged()`，手记卡/手记页/首页徽标改经 `subscribeDailyNoteChanged()` 订阅。
