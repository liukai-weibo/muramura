## 必须实现

- H5 API Client 类型化消费用户列表、角色调整、会话撤销三接口，并执行冻结的运行时响应校验。
- `AuthSession.roles` 仅作入口预门控，最终权限始终由服务端决定；member 不挂载管理组件、不读取管理数据。
- 管理 401 进入既有登录门；管理 403 隐藏入口、卸载全部管理状态并返回“行动”模块，旧响应不得复活页面。
- 搜索 draft 与 applied query 分离；固定 20 条分页；Abort、generation、事实代次和认证上下文共同阻止旧响应覆盖。
- 最终确认时使用 CSPRNG 生成规范 UUID `operationId`；目标级同步写锁阻止双击、重复 Enter 和并发重复提交。
- 角色 unknown-outcome 保留旧事实与目标锁，只能由 unknown 形成后的显式 GET 返回同一 targetId 的合法摘要确认并解锁。
- 会话 unknown-outcome 不得由用户列表或刷新确认；再次撤销必须重新阅读完整确认层并在最终确认时生成新 operationId。
- 明确角色成功只采用服务端真实摘要；明确会话成功只采用服务端撤销计数；不得按请求体乐观更新或自动 GET。
- 当前账号按服务端 userId 判断，不展示内部 id，不提供自身角色或会话管理入口。
- 桌面表格、窄屏卡片、确认层、危险等级、文案和响应式行为遵循设计冻结记录。
