## 已验收行为

- 无 Cookie 和无效 Cookie 调用管理路由时先返回 401；member 对任意管理路径统一返回 403；只有管理员通过授权门后才可观察参数、路由和 64 KiB 请求体限制。
- 管理员用户列表固定每页 20，稳定排序，支持字面量子串搜索和特殊 LIKE 字符转义；只返回脱敏用户摘要。
- 角色授予、撤销、相同状态零写入、成功后真实重读、自操作、目标不存在和 operationId 冲突符合契约。
- 会话撤销只影响目标用户，管理员不能通过管理接口撤销自己的会话。
- 管理写事务内重新确认 actor 管理员身份；并发互撤、失败回滚和 commit 后 unknown-outcome 保持安全。
- `platform_admin` 对其他用户的十个业务集合继续返回既有不泄露 404，列表、搜索、Dashboard、回收站及 Backup 继续受当前 owner scope 限制。
- 非管理路由 64 KiB、Backup restore 16 MiB、CORS、health、既有错误 DTO、requestId 和 no-store 均未回归。
