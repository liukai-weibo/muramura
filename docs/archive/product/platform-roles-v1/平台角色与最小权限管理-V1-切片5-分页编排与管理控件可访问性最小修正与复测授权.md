## E2E 编排修正授权

`tests/platform-administration-v1-slice5.e2e.test.ts` 仅允许：

- 操作 `member_a` 前，以其完整 username 使用既有搜索提交，等待唯一目标行进入当前读模型后再执行既有角色管理动作。
- 操作会话撤销目标前，同样以完整 username 使用既有搜索定位唯一目标行，再执行既有会话撤销动作。
- 每个 unknown-outcome 场景开始前，通过既有清除搜索或空查询明确清除上一场景的 query，并恢复未筛选第 1 页。
- 每次跨目标操作前建立“目标位于当前读模型且行可见”的明确前置条件，不根据创建顺序猜测页码。

必须保留 24 名用户、固定每页 20 条、第 1/2 页覆盖及 `createdAt DESC → userId ASC` 稳定排序。不得减少用户、硬编码目标页、把目标插入第 1 页、修改生产分页、增加自动定位或通过 API 直接写页面状态。

## 单点生产修正授权

`apps/client/src/pages/index/platform-administration.tsx` 仅允许为 `.platform-more-button` 对应的现有 Taro 宿主增加 `role="button"`。

必须保持现有动态 `aria-label`、显示文本、`onClick`、菜单、权限、目标锁、分页和条件渲染不变。不得新增 `tabIndex`、键盘处理、`aria-haspopup`、`aria-expanded`、DOM 包装或替换 Button 组件。

`tests/platform-administration-h5-flow.test.ts` 仅允许补充：

- 动态 `aria-label` 保持不变。
- `.platform-more-button` 具有显式 `role="button"`。
- 既有 `!locked` 显示条件保持不变。

不得修改其他事件、状态、请求次数、权限或交互断言。
