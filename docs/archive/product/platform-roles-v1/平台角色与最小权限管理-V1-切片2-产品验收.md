## 已验收行为

- `AuthUser.roles` 固定排序并在每次认证读取时取得最新数据库角色；缺 member、未知角色或缺表均失败关闭。
- 注册、登录和当前会话不泄露密码、哈希、token、会话秘密或摘要。
- 旧 Cookie 在角色授予或撤销后的下一请求读取最新角色，不需要重新登录或更换 Cookie。
- `platform_admin` 不绕过 owner scope，跨用户资源继续返回既有 404。
- 初始管理员 CLI 的显式参数、数据库与 Schema 6 安全门、首次初始化、同目标幂等、并发互斥、事务回滚及 unknown-outcome 均符合契约。
- Schema 5 下 API 主入口不创建服务器或监听，直接 `/health` 返回脱敏 503。
- 未增加管理 HTTP 路由或 H5 管理入口。
