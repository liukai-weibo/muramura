## Harness 最小修正授权

`tests/helpers/platform-administration-v1-slice5-harness.ts` 仅允许修正 `drop-next-completed-write-response`：

- 继续等待上游目标写入完整完成，并记录真实上游状态、既有脱敏网络事实和 `<redacted>` operationId。
- 向 Chromium 发送既有 HTTP 状态及完整响应体对应的 `Content-Length`。
- 只写出严格少于完整长度、可安全截断的响应体前缀，随后断开 socket。
- 删除与固定 `Content-Length` 冲突的 `Transfer-Encoding`，不得改写状态、DTO 或响应内容。
- 响应体不满足安全截断条件时必须使测试明确失败，不得退回完整响应、空响应、零响应头 destroy 或其他降级路径。
- drop 模式仅作用于一条已完成的目标写响应，不得影响 GET、其他写入或后续请求。

## 完整 QA 复测授权

- 修正后必须原样串行执行切片 5 全部 8 项，不得只重跑两个失败场景。
