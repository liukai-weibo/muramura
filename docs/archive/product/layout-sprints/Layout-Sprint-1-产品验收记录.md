## 五、UAT 发现项：搜索关系语义

### 用户观察

搜索暂时不能以“方法来源复盘”或“历史版本来源复盘”的关系语义找到对应方法结果。

### 现状核对

当前搜索实际覆盖：

- 事项标题与补充说明。
- 所有有效事项对应复盘的正文内容。
- 当前方法内容。
- 历史方法版本内容。

因此，复盘正文并未被排除；缺少的是搜索结果中的关系表达：

```text
复盘命中
→ 该复盘同时是方法证据或方法版本来源
→ 当前只返回复盘 / 所属事项
→ 不额外返回或标注关联方法与版本
```

### 产品定性

- 类型：搜索关系增强需求。
- 优先级：P2。
- 是否阻塞 Layout Sprint 1：否。
- 是否立即开发：否。

### 后续候选需求

未来单独评审“关系型搜索增强”，候选能力包括：

1. 复盘结果标注关联的方法、证据类型和版本。
2. 搜索来源复盘内容时，可同时返回关联方法结果。
3. 点击关系结果时允许选择定位事项复盘或方法证据 / 版本。
4. 避免同一命中产生重复、难以理解的结果。

是否立项由真实使用中的重复频率和定位价值决定，不与 Layout Sprint 2 自动绑定。
