## 二、已验收能力清单

### 1. 方法工作台与搜索规则

- 方法模块采用列表 + 详情工作台，列表承担定位与比较，详情承担阅读、证据、版本与复用操作。
- 支持按方法名称和当前步骤进行局部搜索。
- 支持最近更新、验证次数的稳定排序。
- 全局搜索和仪表盘下钻可跨模块定位方法；外部定位优先于局部搜索，并会清除阻挡目标的本地搜索词。
- 当前选中方法被局部搜索排除时，清除选择并展示未选择状态，不保留不可见的错误选中。

### 2. 证据关系展示与 `unknown` 降级

- 前端通过 `reviewApplication.listMethodEvidenceDetails(methodId)` 消费结构化只读结果，不直接读取 IndexedDB 底层表，不自行推断形成、验证或修订关系。
- `formation`、`validation`、`revision` 分别展示为形成方法、验证方法、修订方法。
- `unknown` 展示为“历史证据”，并明确显示“关系类型无法从旧数据中确定”。
- 关联事项或复盘缺失时，页面正常呈现后端提供的降级数据，不因空 `itemId` 尝试定位。

### 3. 双选项复盘处理

- 复盘中的方法处理收敛为两个可切换业务动作：创建方法、验证 / 修订已有方法。
- 不处理方法不再作为与上述动作并列的第三种业务选择，避免方法发起行动后重复、歧义的复盘决策。
- 既有形成、验证、修订的写入语义保持不变。

### 4. 来源方法默认建议、取消记忆与异步保护

- 由方法发起的事项进入复盘时，默认建议验证来源方法。
- 用户取消该建议后，仅以事项 ID 在当前页面会话内记忆；刷新浏览器后允许重新给出默认建议。
- 异步加载完成后不会覆盖用户已经手动做出的选择或取消操作。

### 5. 改选验证方法时的双关系提示

- 当事项由方法 A 发起、用户在复盘中改选验证方法 B 时，页面同时展示：

```text
本事项由「方法 A」v1 发起
本次复盘将验证「方法 B」
```

- 事项的实际使用方法与本次复盘验证目标被明确区分，不混淆历史使用事实与当前复盘决策。

### 6. 流转历史右侧浮动抽屉

- 事项流转历史以右侧浮动抽屉查看。
- 抽屉打开或关闭不会改变正文布局宽度或推挤事项详情、复盘工作区。
- 既有状态流转记录和状态机规则未修改。
