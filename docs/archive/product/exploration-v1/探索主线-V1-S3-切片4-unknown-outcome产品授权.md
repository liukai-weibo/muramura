## 授权范围

覆盖所有 Track 写入、关联写入和扩展 `POST /api/v1/items` 的超时、断线、页面关闭或响应丢失场景。前端须保留输入和选择，不伪造结果、不自动重发，只通过冻结 API 的真实读取确认事实。

允许修改：

- `apps/client/src/**`；
- 与 unknown-outcome 验证直接对应的 `tests/**`；
- 必要的真实验收记录，以及完成工程验证或 H5 人工验收后当天贡献记录。

## 不允许项

- 修改 API、Application、Repository、Contracts、migration、运行库 DDL/DML、`mysql-data` 或 MySQL 容器/权限配置；
- 新增幂等键、写入结果查询、后台补偿、自动重试、客户端重试或本地成功/失败推断；
- 双写、同步、回填、fallback、浏览器直连 MySQL，或任何新业务语义。

## 验收门

- 可控超时、断线、页面关闭与响应丢失后：草稿和选择保留、无自动重发、无重复写入、只允许真实读取确认；
- MySQL 不可用时诚实呈现既有 `503`，不得降级为空列表或无关联；
- 单元与定向前端测试、typecheck、`build:h5`、`git diff --check` 通过；
- MySQL 不可用或故障注入验证仅可在显式 `.env.uat`、`/health` 确认 `database=knowledge_base_uat` 后执行，并具备日常库前后快照、UAT 前后快照、清理方式和恢复条件。

完成后转 QA 与产品复核。未经两者通过，不得开始切片 5 或最终封板。
