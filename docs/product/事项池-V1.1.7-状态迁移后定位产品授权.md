# 事项池 V1.1.7：状态迁移后定位产品授权

日期：2026-07-27

## 结论

授权实施。该项仅修复状态写入成功后的界面定位，不改变既有状态机或任何写入语义。

## 用户问题

事项从“想试试”改为“以后再说”、或从“已开始”改为“已暂停”后，左侧事项池仍停在旧筛选，用户看不到刚刚迁移的同一事项。

## 冻结规则

- 覆盖“想试试 ↔ 以后再说”“已开始 ↔ 已暂停”“以后再说 → 已放弃”“已暂停 → 已放弃”及“已放弃 → 想试试”七种成功状态迁移。
- 后两种成功迁移后，左侧切至“更多状态 → 已放弃”列表并选中该事项。
- 状态写入由服务端明确成功，并且后续真实刷新结果包含同一事项时，左侧事项池切换到目标状态筛选、定位到该事项所在页并选中该事项。
- 不得使用本地乐观更新、旧列表或时间推断完成定位。
- 写入失败、Abort、503、结果未知或刷新未确认时，保留原筛选、分页与选中；不自动重试、不伪造迁移成功或定位成功。
- 保留既有草稿离开保护和探索事实刷新。

## 授权范围

- `apps/client/src/pages/index/index.tsx`
- 直接前端测试、必要 QA / 产品记录与当天贡献记录

## 明确禁止

- API、Application、Repository、Contracts、数据库、状态机、migration、配置、备份、探索主线关系或任何写入语义修改。
- 新增状态、筛选、路由、缓存、预取、自动重试或 fallback。

## 验收标准

- “想试试 ↔ 以后再说”成功后，左侧切至目标状态并选中该事项所在页。
- “已开始 ↔ 已暂停”成功后，左侧切至目标状态并选中该事项所在页。
- “以后再说 → 已放弃”及“已暂停 → 已放弃”成功后，左侧切至“更多状态 → 已放弃”并选中该事项所在页。
- “已放弃 → 想试试”成功后，左侧切至“想试试”并选中该事项所在页。
- 各类失败或未知结果均不改变当前左侧定位，且不自动重试。
