# 回收站永久删除与批量操作：产品授权

日期：2026-08-09

## 授权范围

- 回收站支持默认展开、展开/收起按钮和 `aria-expanded`。
- 事项、方法、探索主线支持单条永久删除。
- 当前筛选结果支持跨分页全选与批量永久删除。
- 单条和批量永久删除均需二次确认，并明确提示删除后无法恢复。

## 业务边界

- 不改变既有软删除、恢复、备份和自动清理语义。
- 探索主线存在任何关联事项时拒绝永久删除，不解除关联、不级联删除事项。
- H5 为本轮验收目标，微信小程序暂不纳入。

## 验收

重点验收筛选全选、确认层、删除后刷新和关联事项拒绝；工程门为 typecheck、相关测试、H5 构建与 `git diff --check`。
