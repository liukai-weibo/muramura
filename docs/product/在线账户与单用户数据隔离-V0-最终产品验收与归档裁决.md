# 在线账户与单用户数据隔离 V0：最终产品验收与归档裁决

日期：2026-07-30  
状态：产品功能验收、受控 Git 独立归档与最终封板均已完成

## 最终结论

在线账户与单用户数据隔离 V0 已通过产品功能验收并完成受控 Git 独立归档。切片 0–5 的 Schema、认证 API、全业务 owner 隔离、初始归属 claim、用户范围 Backup、H5 登录门和独立临时库端到端 QA 均已满足冻结范围。原 P1“实际 UAT 凭据复用 Git 公开示例值”已完成受控轮换并通过定向安全复测。

本结论不代表已部署到公网或任何运行库，也不代表 UAT 当前可用。V0 已以独立提交 `1ac6021 feat(auth): add single-user data isolation V0` 完成归档并正式封板。

## 已验收能力

- 开放注册、登录、退出和当前会话读取；密码与会话秘密按冻结安全参数存储。
- 所有业务 Repository 以服务端当前会话用户 scope 执行；跨用户读取、写入、关联、删除、恢复和 ID 猜测统一返回不泄露存在性的 404。
- 搜索、Dashboard、回收站及十个业务集合均按 owner 隔离，包括 `method_tombstones`。
- 初始 owner claim 仅接受显式目标账户，具备单事务、前后摘要、重复幂等、混合归属拒绝、失败回滚和 unknown-outcome 显式确认。
- Backup V1/V2/V3 不携带 `userId`/`owner_user_id`，仅导出和恢复当前用户；跨用户 ID 冲突返回 409 且零写入。
- H5 未认证时不挂载工作台；认证写入后必须真实重读 session 才进入；退出成功清除上一用户前端上下文；401、503、Abort、响应丢失和旧请求竞态均保持冻结边界。
