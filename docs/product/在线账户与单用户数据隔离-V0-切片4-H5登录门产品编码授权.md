- 提供注册、登录、退出与会话恢复页面状态；未认证用户不得进入既有业务工作台。
- 既有业务请求依赖 Cookie 会话，不发送或保存可伪造的 `userId`、密码哈希或会话令牌。

## 硬边界与验收

- 不新增邀请、邮件验证、角色、共享、离线缓存/SQLite、同步或桌面原生能力。
- 401 后稳定回到认证门；网络失败、503、Abort 与结果未知不伪造登录或业务成功，不自动重试写入。
- 不能以客户端隐藏替代切片 2 的服务端隔离；不得改变 API、Contracts、数据库、Cookie 安全属性或部署配置。

## 产品验收与归档（2026-07-30）

验收通过。无会话时仅挂载认证入口且业务 GET 为零；登录成功后必须额外以 `GET /api/v1/auth/session` 确认真实会话，才挂载工作台。登录失败、重复注册、初始 session 503、退出 503、任一当前认证上下文业务 401、登录/注册/退出的网络失败、Abort 与响应丢失均按冻结边界处理，保留必要输入或工作台，不伪造成功且不自动重发。旧认证上下文的迟到 401 不得覆盖新会话；退出成功后卸载工作台，再次登录不得复用上一用户的选择、草稿或页面局部状态。

所有请求固定 `credentials=same-origin`，未传递 `userId`、`passwordHash`、`sessionToken`、Authorization 或 Bearer，源码未使用 `localStorage`/`sessionStorage` 保存认证信息。认证浏览器流程 1 文件 7 项、认证专项合跑 2 文件 17 项、直接引用 H5 页面/API Client 回归 14 文件 90 项通过；认证浏览器流程与直接引用回归去重合计为 15 文件 97 项。不得继续引用无法按对应命令复现的“14 文件 / 98 项”。typecheck、`build:h5` 与 `git diff --check` 通过；构建仅保留既有 Sass legacy JS API 弃用警告。

本结论基于构建产物和隔离 Mock HTTP，不验收真实 API Set-Cookie、Cookie 过期、真实 MySQL 503、真实注册写入或受保护数据库 UAT，也不构成 V0 完成或封板。切片 5 独立临时库 QA 授权现生效。
