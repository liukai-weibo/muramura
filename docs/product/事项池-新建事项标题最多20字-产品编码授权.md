# 新建事项标题最多 20 字：产品编码授权

> 日期：2026-07-27
>
> 状态：架构有条件可行；本文件授权最小范围实施与验证。
>
> 产品规则见 `docs/product/事项池-新建事项标题最多20字-产品立项与架构评审授权.md`；运行事实以 `docs/product/当前运行事实.md` 为准。

## 授权结论

授权实施“所有既有新建事项标题最多 20 个用户可见 Unicode 字素簇”。校验必须同时覆盖前端输入、Application 编排和实际 MySQL 写入边界，避免直接 API 或内部链路绕过。

## 允许修改的文件与范围

- `packages/domain/src/index.ts`：新增共享纯校验；复用既有 trim 后，以 `Intl.Segmenter(undefined, { granularity: 'grapheme' })` 计数，最大 20。
- `packages/application/src/index.ts`：在 `ItemApplicationService.createIdea` 与 `MethodApplicationService.createItem` 前校验。
- `packages/storage-mysql/src/item-repository.ts`
- `packages/storage-mysql/src/exploration-track-repository.ts`
- `packages/storage-mysql/src/method-application-repository.ts`
  - 三条 Repository 写入链在任何 `INSERT` 前再次校验，超限零写入。
- `apps/api/src/index.ts`：将既有标题超限校验错误映射为既有 `400 VALIDATION_FAILED + requestId`。
- `apps/client/src/pages/index/index.tsx`
- `apps/client/src/pages/index/exploration-prototype.tsx`
- `apps/client/src/pages/index/index.scss`
  - 不使用 HTML `maxLength`；受控输入超限时保留原合法值，提示“标题最多20个字符”，始终展示 `n/20`。
- 直接测试、必要产品/架构/QA 记录与当天贡献记录。

## 冻结规则

1. 所有既有新建事项入口都受限：全局快速捕获、捕获入口、长期探索内“加入想试试”、方法模块“用此方法开始行动”、“加入以后再说”、内容首行自动生成标题及其他既有 `POST /api/v1/items` 创建路径。
2. 计数复用既有 trim 后的标题值；中文单字计 1，组合 emoji 计 1；20 个允许创建，21 个拒绝。不得截断标题或内容。
3. API 不新增错误 DTO，复用既有 `400 VALIDATION_FAILED + requestId`；不得新增或修改请求 DTO、路由、Contracts、Migration、数据库结构或 Backup V3 格式。
4. 历史超限事项的读取、状态迁移、关联、Backup V3 导入导出均保持兼容；不迁移、不截断、不清库。
5. unknown-outcome、旧请求保护、自动重试边界和既有状态迁移语义不变。

## 验收门

- Unicode 字素簇的 20/21 边界：中文、英文、组合 emoji 和混合输入。
- 所有前端创建入口均展示计数并稳定阻止超限输入。
- 直接 API 超限请求返回既有错误且零写入。
- Item、探索主线原子创建、方法应用三条 Repository 写入链均覆盖超限零写入。
- 内容首行自动生成标题超限时零写入、不截断。
- 历史超限事项及状态迁移、关联、读取、Backup V3 导入导出保持兼容。
- 既有 unknown-outcome 回归、定向测试、typecheck、build:h5 与 `git diff --check` 通过。

## 不授权

任何不在上述文件清单内的改动；尤其是 DTO、路由、Contracts、Migration、数据库、配置、Docker/MySQL、Backup V3 格式、状态机、关联语义或远程能力。

研发完成后必须转 QA；未经 QA 通过与产品验收不得归档或宣称完成。
