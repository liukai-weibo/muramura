## 一、验收结论

“方法生命周期治理 Sprint”完成并正式封板。

本轮建立了方法从正常可用、移入统一回收站、30 天内恢复，到期永久清理正文并保留最小历史墓碑的完整生命周期。历史行动、复盘与证据关系不会被伪装为“从未关联方法”；回收站中的方法不能再用于行动发起、验证、修订、编辑或搜索。

```text
正常可用方法
→ 移入回收站（30 天内完整可恢复）
→ 到期永久清理方法正文与版本正文
→ 仅保留最小历史墓碑解释既有关系
```

## 二、已验收能力

### 1. 方法回收站与恢复

- 方法详情通过低频路径操作：`··· 更多操作 → 移入回收站 → 二次确认`。
- 点击更多操作只打开局部菜单；菜单外点击和 `Esc` 只关闭菜单，不产生写入。
- 确认层默认焦点为“取消”；仅用户确认后调用方法生命周期 Application 服务。
- 移入成功后，当前方法详情选择及局部展开状态收敛，活跃方法列表刷新，不自动跳转到回收站。
- 统一入口为“数据与设置 → 回收站”，支持 `全部 / 事项 / 方法` 筛选。
- 回收站中的方法可在 30 天内恢复；恢复后重新进入活跃方法列表与既有可用范围。

### 2. 生命周期操作边界

回收站期内的方法保留完整方法本体、版本、证据与既有关系，以支持原样恢复；但从以下正常工作流中排除：

```text
默认方法列表
全局搜索
用此方法开始行动
复盘默认验证建议
验证候选
修订候选
编辑入口
```

历史位置基于结构化状态诚实展示：

```text
关联方法：{title}（已移入回收站）
关联方法：{title}（已永久清理）
```

两种状态均只允许完成事实复盘；不得自动关联、验证、修订、重连或推断其他方法。

### 3. 最小历史墓碑

- 方法到期永久清理后，删除方法本体、具体步骤、适用 / 不适用情况与版本正文。
- 仅保留最小墓碑，用于解释仍存在的 `MethodEvidence` 或 `MethodApplication` 历史引用。
- 墓碑不参与方法搜索、行动发起、验证、修订、编辑或恢复完整正文。
- 当所有历史承载关系均被永久清理、无任何引用时，墓碑一并清理。
- 不通过名称、时间或版本号猜测或重连历史关系。

### 4. 数据安全与备份兼容

- 完整 JSON 备份升级为 v2，包含 `methodTombstones`。
- 系统仍兼容导入 v1 备份。
- 必填引用继续严格校验；不伪造缺失对象、不自动重连关系。
- 数据可信性与备份恢复 P0/P1 已在独立 QA 中关闭：系统自产完整备份可由系统自身安全恢复，关联断裂可通过结构化状态诚实降级。
