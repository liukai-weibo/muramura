# 探索主线 V1.2：统一回收站入口产品授权

日期：2026-07-27

## 产品裁决

架构结论为“有条件可行”。现授权以统一回收站展示既有已删除探索主线，不改变删除、恢复或关联语义。

## 冻结规则

- TrashFilter 固定为 `all`、`item`、`method`、`exploration-track`；`all` 包含三类事实。
- TrashEntry 增加 `type=exploration-track`，仅携带既有 `id`、`title`、`deletedAt`。
- 排序固定：`deletedAt DESC → item/method/exploration-track → id ASC`。
- 删除主线仍在探索主线模块发起；移除探索主线模块内已删除主线的查看和恢复入口。
- 恢复探索主线继续调用既有恢复路由；恢复后重读当前回收站、事项数据和活跃主线列表。关联事项仅按既有语义重新可见。
- 事项和方法保留既有“30 天”表述；探索主线显示“当前不自动清理，可在此恢复”；`all` 不显示统一剩余天数。
- unknown-outcome 仅单次请求，无自动重试；仅允许显式重读确认。

## 禁止修改

- Repository、migration、数据库、配置、备份格式、状态机、关联或删除恢复语义。
- 永久删除、批量操作、搜索、新路由、自动重试、fallback 或本地成功推断。

## 验收

- 四个筛选与 all 三类覆盖、固定排序及三类文案正确。
- 探索主线恢复复用既有路由并重读所需事实；关联不被重建或改写。
- unknown-outcome 无自动重试。
- 定向测试、typecheck、相关 API 测试、build:h5 与 `git diff --check` 通过。
