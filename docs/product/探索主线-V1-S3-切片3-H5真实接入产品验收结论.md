## 验收依据

- QA 未调用真实 API、未执行运行库写入或浏览器破坏性 UAT；已完成本地静态与定向前端验证。
- GET 通过 Adapter 读取；切换事项会取消旧读取，旧请求不能覆盖当前 Context。
- available 仅在真实可用时开放调整与移除；track-deleted 显示真实已删除主线名称与“已删除”状态，不显示调整、移除或选择器；unavailable 保持只读提示；no-association 为明确空态，读取失败不伪装为空态。
- 选择器取消零写入；PUT 仅使用冻结 `{ trackId }` body，DELETE 无 body；草稿失败保留与请求序号保护已验证。
- typecheck、定向测试（2 文件、11 用例）、`build:h5` 与 `git diff --check` 通过。入口体积和 webpack 缓存序列化警告未阻断构建。
- 设计冻结已修订：track-deleted 调整或移除稳定拒绝且零副作用；恢复原主线仅通过已删除主线管理区。
