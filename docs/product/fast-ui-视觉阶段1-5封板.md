# fast-ui 视觉阶段 1-5 封板

> 封板日期：2026-08-12
>
> 适用分支：`fast-ui`

## 封板结论

视觉阶段 1-5 已完成产品人工复验并封板。该阶段建立了桌面端优先、H5 可降级的奶油线稿视觉基线；其目标是让行动信息保持可扫描，同时用低饱和暖色、白色浮层和本地猫咪线稿建立稳定的品牌辨识。

后续页面新增、页面重构和展示层缺陷修复默认复用本阶段规范。不得以视觉封板为由变更业务对象、状态机、数据来源、API、Contracts、Application、数据库、备份或微信端。

## 已封板范围

- 首页从自动轮播改造为“今日推进”行动主控台，保留真实事项和 `DashboardReport.backlog` 读取边界。
- 三张行动指南使用本地透明猫咪线稿、暖米视觉区和破框层次；指南阅读浮层为本地展示，不请求或写入数据。
- 桌面侧栏、顶部轨道、首页、行动工作台、探索、方法、数据管理、我的、AI、认证页及常用浮层采用统一奶油浅色与暖棕深色 Token。
- 普通可点击卡片、按钮、导航和列表选中态采用原生 CSS 贝塞尔反馈；危险操作、窗口控制、输入编辑和拖拽不使用缩放反馈。
- 首页指南卡支持“玻璃效果”和“兼容模式”；浅色/深色主题和显示效果均为当前设备本地偏好。
- 桌面端与 H5 均复用主题偏好；账户区提供显示效果入口，桌面/H5 顶栏提供主题切换入口。

## 明确不在本期范围

- 不新增“专注模式”、AI 晨报、动态流、指南内容系统、服务端同步或账户级视觉偏好。
- 不将猫咪插画替换为外部素材、3D/C4D 素材或在线资源。
- 不引入 Tailwind、Framer Motion、JS 弹簧动画、全局状态库或新的 Tauri/Rust 依赖。
- 不改变 Rive 桌宠、AI 流式渲染、全局搜索、快速捕获、事项状态迁移或窗口控制的业务语义。

## 复验事实

- 已完成桌面端人工检查：浅/深主题、玻璃/兼容模式、首页猫咪卡、侧栏与顶轨、列表选中态及常规悬停反馈。
- 已通过 `corepack pnpm typecheck`、`corepack pnpm --filter @knowledge-base/client build:h5` 和 `git diff --check`。
- 集成显卡的长期帧率与输入延迟结论只能在目标设备实测后记录；当前“兼容模式”的保证是静态禁用页面 `backdrop-filter`，不宣称未经实机测量的性能数据。

## 后续变更规则

1. 纯展示层的新页面或局部调整，先引用 `docs/design/奶油线稿全局视觉规范.md`，再在现有主题 Token 与交互类内实现。
2. 涉及新的数据、状态、路由语义、API、Schema、备份或跨模块定位契约时，先走产品与架构评审；视觉规范不构成这些改动的授权。
3. 新增可交互控件时，先判断其是否属于普通操作；只有普通操作才可使用 `control-transition`。危险、窗口、输入、滚动和拖拽控件保持专属行为。
4. 新增插画只可使用仓库本地的暖白填色、深棕线稿猫资源，并遵循资源复用和无网络依赖约束。
