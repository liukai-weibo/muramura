# 数据与设置：统计与恢复预览补全产品授权

日期：2026-07-29

## 结论

授权实施数据与设置页面的纯展示补全。复用既有前端状态与 Backup V3 已有 `explorationTracks` 数据，不新增任何读取、字段或恢复能力。

## 冻结规则

- 桌面端“本地数据状态”四项统计固定为一行、等宽展示：有效事项、当前方法、探索主线、回收站。
- 窄屏可降为两列或单列，文字不得被压缩、遮挡或截断。
- “探索主线”仅展示真实活跃主线数量；已删除主线不计入，继续仅属于回收站。
- 选择合法 Backup 后的恢复确认信息统一展示：`X 条事项 · X 条复盘 · X 条方法 · X 条探索主线`。
- 该数字仅用于明确告知将恢复的既有 Backup 内容；不改变恢复范围、覆盖语义、确认层、unknown-outcome 或失败边界。

- 宽桌面下四张统计卡始终同一行且视觉等宽；小屏正常响应式降级。

- Backup V3 恢复确认准确显示探索主线数量，包括零条与多条边界。
- 通过直接前端测试、`typecheck`、`build:h5` 与 `git diff --check` 后转 QA。
