# 在线账户与单用户数据隔离 V0：产品立项与架构评审授权

日期：2026-07-29  
状态：已立项，仅授权架构评审与任务书；未授权编码

## 用户问题

当前系统仅面向单个个人数据集运行。用户希望以功能和上线速度优先，先开放公网 Web 与后续 Tauri 桌面端第一版所需的最小账户能力：注册、登录、退出，以及每个账户只能读取和操作自己的数据。

## 目标

在独立本地开发/测试环境中，形成一份可实施、可验证、可回滚评估的最小技术任务书，为“在线账户与单用户数据隔离 V0”确定可信的数据归属、鉴权和备份边界；本次不实施任何代码或数据库变更。架构任务书通过后，另行申请独立编码授权。

## 已冻结产品范围

- 开放注册、登录与退出；不引入第三方登录。
- 仅支持单用户数据隔离：认证后的当前用户只能读取、写入、删除、恢复和备份自己的数据。
- 隔离范围覆盖事项、方法、复盘、探索主线、回收站与 Backup 的导出、预览、校验和恢复。
- 既有个人数据只允许通过一次显式、可验证的“初始账号归属迁移”进入新模型；必须由架构师说明前置条件、失败处置、幂等性与可审计证据。
- 密码必须使用安全密码哈希；会话必须使用安全 Cookie，而不是由前端传入或保存可伪造的用户身份。
- 自动化测试只能使用独立临时数据库或独立本地开发/测试环境，不得复用日常库、UAT 库或任何既有运行库。
- V0 可继续使用 `http://公网IP:10086` 作为 Web 入口，并作为后续 Tauri 桌面端第一版的服务入口；架构师须仅评估实现边界，不得将此授权扩张为 HTTPS、域名、CORS 放宽、远程 MySQL 暴露或其他公网基础设施改动。

## 非目标

- 邀请制、邮件验证、团队、角色、RBAC、协作、共享、公开链接、组织/工作区、离线 SQLite、离线编辑、多端同步、云端同步、第三方 OAuth、找回密码、域名、HTTPS、备案、限流与桌面原生增强。
- 修改当前本地日常 `knowledge_base`、`knowledge_base_uat`、其数据、migration record、Backup 或运行配置。
- 在本次立项阶段编写或修改 Contracts、Migration、API、Application、Repository、前端、Docker、Nginx、`.env`、数据库或测试代码。

## 必须保持的可信边界

- 数据归属和访问控制必须由服务端认证会话决定；不得接受前端提交的 `userId` 作为归属或授权依据。
- 每个涉及业务数据的读取、写入、回收站操作和 Backup 操作都必须有同一条可追溯的当前用户校验链，不能只在 UI 隐藏其他数据。
- 初始账号归属迁移不得默认猜测账号、批量归属或污染已有数据；架构任务书必须明确一次性触发条件、验证证据、重复执行行为、失败回滚/零污染策略及历史备份兼容策略。
- unknown-outcome 不自动重试；认证、写入、恢复和迁移的结果未知时只能以显式受控读取确认。
- HTTPS、服务端 Backup 恢复、邮件验证与限流均后置，不是本 V0 的编码或测试阻断项；其缺失不得被表述为已满足生产安全门。

## 架构评审任务书要求

架构师须基于当前 MySQL + Node API + Application / Repository 分层，输出最小任务书并逐项裁决：

1. **Contracts**：认证请求/响应、会话可见错误与既有业务 DTO 的最小边界；哪些身份信息绝不暴露给前端或写入业务 DTO。
2. **Migration**：账户、会话及所有业务数据归属所需的最小 schema 演进、索引、外键/约束、回滚与旧数据处理；明确初始账号归属迁移是否应与 schema migration 分离。
3. **API**：注册、登录、退出、会话查询及现有业务 API 的认证接入方式、Cookie 属性、CSRF/跨域边界、401/403 错误映射和 requestId。
4. **Application**：当前用户上下文如何进入所有业务编排、创建/读取/状态迁移/删除恢复/Backup 的授权校验点，以及不得由前端代为过滤的边界。
5. **Repository**：所有查询和写入的用户范围约束、跨用户 ID 探测防护、事务与初始归属迁移的原子性。
6. **Backup 兼容**：用户范围内的 V3 导出、预览与恢复；旧个人 Backup 的归属规则、跨账户恢复拒绝策略与恢复零污染门。
7. **测试**：独立临时数据库策略，密码哈希与 Cookie 安全测试，跨用户读取/写入/ID 猜测/回收站/Backup 隔离，初始迁移成功/重复/失败，unknown-outcome、503 与既有单用户回归。
8. **实施切片与允许文件**：按可独立验收的最小切片列出精确文件范围、每片验收门和不可开始的后续片；不得将正式云端上线门混入本地开发切片。

## 当前裁决

仅允许架构师进行只读评审并输出上述任务书。未经产品对任务书和每个实施切片签发独立书面编码授权，不得开始任何实现、迁移、测试环境创建、配置变更、运行库操作或部署改动。
