## 授权范围

以 API Client / Adapter 取代探索主线原型 fixture，并按冻结设计接入已冻结 API 的结构化读模型与写入操作。实现真实 loading、空态、读取/业务错误、已删除只读、unavailable 只读、草稿和明确选择保护，以及旧请求不得覆盖用户当前上下文的竞态保护。

允许修改：

- `apps/client/src/**`；
- 与 H5 真实接入直接对应的前端 `tests/**`；
- 必要的真实设计/验收记录，以及完成工程验证或 H5 人工验收后当天贡献记录。

## 不允许项

- 修改 API、Application、Repository、Contracts、migration、运行库 DDL/DML、`mysql-data` 或 MySQL 容器/权限配置；
- 新增或变更路由、DTO、业务对象、字段、状态、关系、筛选、计数或任何业务语义；
- IndexedDB / SQLite / localStorage 业务持久化、双写、同步、回填、fallback 或浏览器直连 MySQL；
- 实现 unknown-outcome 的端到端策略、自动重试、幂等键、后台补偿或本地成功推断；
- 修改既定桌面/小屏信息层级、两行截断规则或冻结文案语义。

## 验收门

- 探索主线页面真实读写仅经 loopback API Client / Adapter；fixture 不再参与真实读写；
- 结构化 API 事实是唯一展示来源，前端不从标题、时间、状态文案、计数、历史或缓存推断关联；
- loading、空态、读取失败、业务错误、deleted、unavailable、取消零写入、草稿保护和请求竞态均有前端测试；
- 通过 typecheck、前端测试、`build:h5` 与 `git diff --check`；任何实际 API 运行时测试先以 `/health` 确认目标库；
- 浏览器破坏性 UAT、MySQL 不可用与 unknown-outcome 端到端验收不在本切片执行，留待切片 4/5。
