# 需求池

> 状态：当前有效的未立项需求入口。
>
> 规则：此处只记录尚未进入冻结 Sprint 的问题、机会与风险。条目不是开发指令；涉及数据模型、状态机、删除恢复、契约、备份或迁移的事项，必须先经过架构评审。

## 使用规则

1. 先记录真实问题与证据，再讨论方案；不因页面留白或实现便利新增能力。
2. 已封板 Sprint 不插入需求；新事项必须在这里获得独立范围、优先级与验收条件后才可立项。
3. `待观察` 不允许写代码；`待架构评审` 不允许前端先行兜底；`已拒绝` 不得以换名方式重新进入开发。
4. 只有跨项目、跨阶段、六个月后大概率仍成立的原则进入长期层；本文件仅保存项目需求决策。
