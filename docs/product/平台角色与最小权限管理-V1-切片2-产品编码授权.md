## 必须实现

- `AuthUser.roles` 必填、去重并按 `member`、`platform_admin` 固定排序；缺 member、未知角色、缺表或读取失败必须失败关闭。
- 注册用户只获得 member；登录及每次旧 Cookie 会话读取必须从数据库取得最新角色，不缓存、不写入 Cookie 或 `user_sessions`。
- `AuthCredentialRecord` 固定为 `{ user, passwordHash }`；密码哈希只能用于登录校验，不得进入 `AuthSession`、HTTP 响应或日志。
- 初始管理员 CLI 只接受显式 `userId`、`expected database` 与 `apply`；已有其他管理员时拒绝，同一目标已初始化时零写入返回 `already-initialized`。
- API 监听前及 CLI 任何写入前确认实际目标数据库与 Schema 6；Schema 5、错误数据库、缺表或 MySQL 不可用均拒绝。
- commit 后结果未知不得自动重试；只能显式重读角色与审计确认事实。
- 管理员角色不得进入 `CurrentUserScope`，不得改变十个业务集合的 owner 隔离。
