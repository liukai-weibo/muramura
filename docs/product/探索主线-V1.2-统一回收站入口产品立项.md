# 探索主线 V1.2：统一回收站入口产品立项

日期：2026-07-27

## 用户问题

已删除探索主线的查看与恢复入口位于探索主线模块，而事项和方法位于“数据与设置 → 回收站”，入口分散。

## 目标

在统一回收站集中查看和恢复已删除的事项、方法与探索主线。

## 冻结产品规则

- “数据与设置 → 回收站”筛选固定为：全部、事项、方法、探索主线。
- “全部”包含三类真实删除条目，不得遗漏探索主线。
- 已删除探索主线从探索主线模块移除查看/恢复入口；探索主线模块保留发起删除操作。
- 回收站中的探索主线仅展示真实删除事实并提供既有恢复；恢复后，既有关联事项重新按现有语义可见。
- 不改变关联、删除、恢复、历史、状态机或备份语义。
- 不沿用事项/方法“30 天自动永久清理”文案到探索主线，除非架构确认既有真实数据语义完全一致。

## 非目标

- 新增永久删除、批量操作、搜索、回收站新路由或新的删除保留期。
- 修改 API、Contracts、Application、Repository、数据库、migration 或备份格式；是否必需由架构评审裁决。

## 架构待裁决

- 既有已删除探索主线列表与恢复能力能否组成统一回收站的可信读模型。
- 若需扩展 TrashFilter / TrashEntry，最小契约、API 和 Application 改动。
- 三类条目的稳定排序、恢复后的刷新与历史关联边界。
- 探索主线删除事实的真实保留期与回收站文案。
