# 奶油线稿全局视觉规范

> 状态：全局通用设计基线，来源于 fast-ui 视觉阶段 1-5 封板。
>
> 适用：后续桌面端与 H5 的新增页面、模块、浮层和普通交互。

## 设计定位

MaruMaru 使用“暖白填色、深棕线稿、低饱和暖粉强调”的平面视觉语言。界面服务于个人行动闭环：信息优先、品牌插图克制出现、层级清晰而不堆砌装饰。

不要使用纯黑、冷蓝紫渐变、高饱和橙绿渐变、3D/C4D 素材或非本地插画。猫咪仅作为品牌、空态或低频内容插图，不承担导航或功能性图标的语义。

## 三层空间结构

```text
基础层：暖灰画布 / 浅奶茶侧栏
中间层：白色实底的操作卡、数据卡、列表与表单
顶层：仅在需要强调内容时使用玻璃卡、弹窗、抽屉与破框猫咪
```

- 桌面侧栏：`#F3EFEA`，右侧 `1px #EAE6E0` 分隔线。
- 主画布：`#FAF8F5`；避免让侧栏、画布和白卡片使用近似色而失去边界。
- 普通卡：白色表面、`1px solid #EAE6E0`、`22px` 圆角和暖调基础阴影。
- 顶层玻璃：只用于少量内容型卡片；兼容模式回退为高不透明暖白卡。

## 色彩与文字 Token

| 用途 | 浅色值 | 深色原则 |
| --- | --- | --- |
| 画布 | `#FAF8F5` | 暖深棕 `#292521` |
| 侧栏 | `#F3EFEA` | 暖棕 `#37322E` |
| 分割与描边 | `#EAE6E0` | `#4A453F` |
| 标题 | `#2C2823` | `#F3EFEA` |
| 正文 | `#544F49` | `#C9C3BB` |
| 辅助文字 | `#948E86` | 保持低对比但可读 |
| 选中/主操作 | 低饱和暖粉 | 降低亮度后的暖粉/玫棕 |

标题、正文和辅助文字必须使用三档层级，不以单一灰度代替。危险、错误、离线仍保留语义颜色，但不能抢占普通行动与内容的视觉焦点。

## 尺寸、圆角与节奏

- 桌面首页内容最大宽度：`1000px`；默认内边距：`24px 32px`。
- 模块间距与常规卡内边距：`20px`。
- 普通卡片：`22px` 圆角；内层插图或小面板：`12px` 圆角；标签：`14px` 圆角。
- 普通文字按钮：最小高度 `38px`、左右内边距 `14px`、字号 `12px`、圆角 `9999px`。
- 图标按钮：固定正方形尺寸；不以文字胶囊替代已有标准图标。
- 正文默认行高：`1.6`；紧凑工作台维持现有密度，不因全局视觉规范被强行改成大卡片布局。

## 卡片、按钮与状态

### 卡片

普通信息卡使用白色实底、细描边、基础双层暖调阴影。悬停只增加轻微上浮和强化阴影，不改变内容尺寸或压迫相邻元素。

### 按钮

- 主操作：低饱和暖粉渐变，白色文字；只保留当前任务最重要的一个主操作。
- 次操作：暖白底、细描边、深暖文字。
- 危险操作：保持独立危险语义，不套用普通缩放或暖粉渐变。
- 禁用和提交中：不触发悬停缩放或阴影强化。

### 列表与页签选中态

行动事项、长期探索、方法、AI 会话和“我的”页签使用同一语言：暖粉渐变、左侧 3px 强调线、暖调描边与小幅位移。悬停态必须保持文字对比，不可刷成纯白或覆盖选中反馈。

## 动效与可访问性

- 只使用 CSS `transform` 与 `transition`；曲线为 `cubic-bezier(0.34, 1.56, 0.64, 1)`，时长约 `250ms`。
- 普通卡与按钮最大为轻微上浮和约 2% 缩放；侧栏导航采用横向 1-2px 位移，避免挤压相邻项。
- 对实际缩放元素使用 `will-change: transform` 与 `backface-visibility: hidden`，避免低 DPI 文字模糊。
- `prefers-reduced-motion: reduce` 必须移除新增的过渡、位移、缩放和合成层提示。
- 仅在支持 hover 的设备启用悬停反馈；触屏设备保留点击状态，不依赖 hover 才能理解功能。

## 主题与显示效果

- 主题为手动浅/深两态；默认浅色，不跟随系统。
- 深色模式保持暖棕层级，禁止纯黑和冷灰；白色填充、深棕线稿猫必须清晰可辨。
- 玻璃效果默认应用于少量内容型卡片；兼容模式关闭全页面模糊滤镜，改用高不透明表面和清晰边界。
- 新页面不得自行发明第三种主题、额外性能开关或独立偏好键；复用既有主题与显示效果状态。

## 猫咪插图规范

- 只使用仓库中的本地透明 PNG，视觉语言为暖白填色与深棕线稿。
- 指南卡插图区域统一暖米色 `#F4F1EA` 或 `#FAF8F5`，不使用高饱和渐变。
- 需要破框时：外层卡和插图区允许 `overflow: visible`，猫咪绝对定位，配合柔和 `drop-shadow`；正文层和窄屏不得被遮挡。
- 猫咪不重复堆叠。每个页面优先只保留一个明确的品牌或内容插图落点。

## 新页面实施清单

1. 先确认页面是纯展示层；若包含新业务能力，先完成产品与架构评审。
2. 使用现有 `cream-ui-theme.scss` Token、交互类与主题属性，不新增平行色板。
3. 建立基础层、操作层、顶层的明确边界；不把整个页面卡片化。
4. 为加载、空态、错误态、危险操作和窄屏给出稳定的视觉降级。
5. 检查浅色、深色、玻璃、兼容四种组合下的文字、边界、输入焦点和插图对比。
6. 检查 720px 以下无横向溢出，且动效在低动态效果偏好下完全降级。
